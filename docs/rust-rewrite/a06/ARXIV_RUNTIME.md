# Developing actual arXiv runtime

The registered factory uses F08 HTTP injection and the accepted supervised raw Atom operation. Admission is acquired before query construction and HTTP. One operation Budget/deadline covers the charged source query, retained visible response bytes, borrowed header descriptors, selector/body decoding, Expat parse, projection and retained result batch. The existing helper performs parsing; the runtime never calls the legacy parser path.

A finite caller SearchContext is an absolute whole-operation limit. The configured source timeout also bounds HTTP and intersects that context. For a call without SearchContext, admission is awaited before the configured timer starts; only caller SearchContext bounds admission. Direct legacy calls use a finite positive configured timeout as their explicit bounded-operation policy; nonpositive values time out, and nonfinite/unrepresentable timeouts without a finite caller context return `arXiv requires a finite execution deadline`. This whole-operation limit is intentional and distinct from the Python adapter's per-request timeout.

Eight unchanged historical captures provide302 exact reachable arXiv outcomes and engine-owned request traces, including28 configuration max_results scalar cases. The frozen eligible-ID manifest binds306 unique eligible records. Two original source declaration records retain the separately approved Expat semantic delta; invalid raw-header and unavailable original network exception-text records remain named transport boundaries. This does not qualify every source configuration row or every transport-owned HTTP header.

The additional fifteen whole-original redirect captures bind exact raw-authority policy outcomes: explicit default ports remain distinct from absent ports; HTTP-to-HTTPS with the same explicit port is permitted; Unicode and punycode spellings remain distinct; ASCII/Unicode lowercase follows pinned Python Unicode16; raw IPv6 spellings remain distinct; invalid Location ports fail before host policy. Fourteen added request traces match exactly. The IPv6 fixture explicitly retains both differing initial request URLs: HTTPX preserves the expanded configured spelling while F08's URL type canonicalizes it. The alias is still rejected by the raw policy. No canonicalized comparison hides that mismatch.

Location is read through the accepted shared HTTPX header reader: global UTF8/Latin1 choice, ordered duplicate join, absent/empty distinction and charged cooperative copy. Raw hostname identity lower preserves the suffix after the first percent. This narrow implementation does not claim broad urllib/url parser equivalence. An additional wire-host check refuses a target if native parsing interprets a different authority. Unsupported URL parser failures remain typed transport errors, never fabricated resource failures. Exact malformed-URL diagnostic equivalence outside captured controls remains unqualified.

Seven runtime unit controls cover resource refusal before HTTP, repeated charged query-copy Pending polls followed by drop/real deadline, direct-call deadline policy, encoder-owned real deadline, and charged raw redirect copy cancellation/real deadline. Actual loopback controls observe the HTTP request before cancel/shutdown/parent Tokio deadline, then socket EOF and restored admission; a withheld response proves no parser starts. Existing actual helper controls cover child PID handshake, kill/reap and lease restoration. Parent Tokio deadline tests do not claim child stdInstant expiration or native CPU evidence.

F08/G02 remains open: opaque HeaderValue/cookie/pool/socket backing and pre-handoff allocation peaks cannot be proved from visible lengths. Body capacity and visible headers are charged only after transport handoff. Native URL parsing/serialization includes synchronous library work and opaque allocations; raw cooperative scans do not prove that work's CPU/memory bound. The invalid configured-URL regression captures the original zero-request diagnostic and explicitly asserts the differing native InvalidRequest diagnostic; invalid injected status codes return InvalidResponse before any parser starts. The original network-exception diagnostic and IPv6 wire spelling differences remain explicit transport handoffs. No production provider calls, new runtime Python, extra parser process or independent quota are introduced.

This component does not complete A06. Actual bounded Semantic Scholar and OpenAlex factories, OpenAlex absolute-date request/row proof for984, integrated HTTP/MCP/portal/cache and platform/resource qualification remain separate required work.
