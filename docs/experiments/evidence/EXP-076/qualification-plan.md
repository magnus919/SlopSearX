  and committed source revision in the qualification manifest. Reuse the
  generic HTTP transport only with its exact source hash and unchanged semantics.
- Rebuild all candidate requests from the fixed inputs and match the sealed
  capacity preview. Test original/reverse/rotate/shuffle input orders, canonical
  question insertion and exact stable identity maps. Independently byte-compare
  ordinary W0 to its pinned production contract.
- Parse complete ID-keyed score fixtures with ties and shuffled answer order;
  independently recompute both full permutations and exact Fraction fusion.
  Reject missing/extra/duplicate IDs, nonfinite or out-of-range scores and
  unknown usage atomically.
- Exercise pre-dispatch construction timeout, dispatched timeout, malformed and
  partial response, HTTP failure, response overflow, cancellation and receipt
  failure. Preserve known/unknown usage, full native incumbent fallback, actual
  dispatch counts and uninvoked suffix; never substitute the independent W0
  comparator as production fallback or retry a failed call.
- Check aggregate reservations before every physical request. Verify source,
  runtime, input, manifest and output tampering is rejected before DNS or key
  access. Use a temporary lease location only in explicitly offline fixtures;
  verify exclusive durable creation and stable identity across qualification
  revisions. Never create or delete the real study lease during tests.
- Run a complete 44-call local fixture packet through the real raw verifier and
  both-assessor analyzer path. Test-only nonsynthetic metadata must remain
  clearly labeled as fixture data. Keep source-closure validation active; any
  fixture manifest lookup substitution must be narrow and documented. Assert

  identity guard can fail independently of useful count and facet retention.
- Root must run applicable offline tests on the integrated committed source,
  complete one substantive implementation review and resolve its findings,
  then perform a committed-source admission smoke without provider access or
  credential reads. Fixture success proves mechanism integrity, never quality.
