# Completed passage-reference comparison

All eight fresh answers and two planned independent advisory assessments completed. No searches, Brave, Jev calls, new source captures or retries occurred. Inputs are four exposed contexts; this is neither selector qualification nor untouched confirmation.

| Reference format | Claims | Valid references | Invalid references |
|---|---:|---:|---:|
| Copied whole passage | 31 | 27 | 4 |
| Passage identifier | 37 | 37 | 0 |

All four ID answers had at least one claim and every reference resolved to a passage delivered in its own context with matching source identity. The four quote failures came from one answer; the other three quote answers passed. This demonstrates bounded mechanical validity and a descriptive difference in this run. It does not demonstrate a population error reduction, entailment, usefulness or production transfer. The quote arm copied whole passages of up to 600 characters, unlike the earlier pilot's short quotations, so the earlier pilot is not its control.

Reviewer 1 judged all eight tasks incomplete. Reviewer 2 judged the same W0 flaky-test context complete in both formats and the other six answers incomplete. Neither reviewer reported a task-completion increase from ID references. Some facet judgments favored ID answers, but completeness and unsupported-claim judgments disagreed. Reviewer 2 omitted the required unsupported-claim-index field in 21 of 24 facet records. Those omissions are retained as structural assessment failures, represented by null rather than invented empty lists; this prevents the registered two-assessor no-observed-harm check from being established. No assessments were repaired or rerun.

The assessor contract was frozen after the first two answerer dispatches but before root inspection of their answers and before any assessor dispatch. The initial registration seal covered answerer materials only; this timing deviation is disclosed. All eight answer hashes and the once-randomized anonymous assessment packet were frozen before grading. Both reference forms were resolved to supplied passage text for assessment; invalid links had no evidence text. Wording may reveal format despite removal of format labels, so blinding is imperfect. Model alias/immutable-checkpoint limitations remain.

## Decision

The ID format passed the bounded mechanical process-validity test. Answer utility remains unproved, the advisory noninferiority check is incomplete, and no selector or runtime feature qualifies. This result justifies using verified identity references in a future registered evaluation, while continuing to judge source applicability and claim entailment separately. It does not justify tuning ranks against exposed reference grades or relaxing the complete-pool production gates.
